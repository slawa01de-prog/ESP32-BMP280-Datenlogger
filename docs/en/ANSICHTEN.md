## WebGUI

![Web interface](../images/webgui-vorschau.svg)

Schematic preview based on the webpage included in firmware V7.4.3.
It shows readings, storage, logger controls, calibration, Wi-Fi, OTA and MQTT.
Layout details are simplified; values are examples. The preview uses German labels.

## Desktop GUI for Windows

![Desktop GUI](../images/pc-gui-vorschau.svg)

Schematic preview based on `bmp280_logger_v74_gui.py` (GUI V7.4.2).
It shows **Grafiken (Graphs)** with module selection and separate temperature/pressure charts.
Other tabs: Nodes, Pairing, Analyse (Analysis), Kalibrierung (Calibration), Modul-Steuerung (Module Control), Export and Terminal.
Fonts, window borders and spacing may differ on Windows.
This is not a screenshot captured on Windows; the preview retains German UI labels.
